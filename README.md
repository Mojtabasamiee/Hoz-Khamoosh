# حوض خاموش — THE SILENT POOL
### بازی ترسناک روانی سه‌بعدی اول‌شخص | سازنده: SAMIEE GAME STUDIO (SGS)

## معرفی
«حوض خاموش» یک بازی ترسناک روانی سه‌بعدی اول‌شخص است که در خانه‌ای سنتیِ متروکه در **کاشان** می‌گذرد. بازیکن پس از دریافت نامه‌ای دست‌نویس از مادربزرگ، شبِ بارانی به خانه بازمی‌گردد؛ خانه‌ای با حیاط مرکزی، حوض فیروزه‌ای، انار کهنسال و رازی که سال‌ها زیر زمین دفن شده است.

- **موتور:** Godot Engine 4.7 (GDScript)
- **سکو:** Android (اندروید ۷ به بالا) + دسکتاپ برای تست
- **مدت بازی:** حدود ۳۰ تا ۴۵ دقیقه
- **زبان:** فارسی کامل (راست‌به‌چپ، فونت وزیرمتن — لیسانس OFL)

## امکانات
- خانه سنتی کامل و به‌هم‌پیوسته: هشتی، حیاط مرکزی با حوض، اتاق نشیمن، آشپزخانه، اتاق مادربزرگ، اتاق مطالعه، حمام، انباری، راهرو غربی و **زیرزمین مخفی**
- **۵ پازل عملکردی:** جعبه فیوز، عکس‌های خانوادگی (کد عددی)، ساعت دیواری (۳:۱۵)، مکانیزم آب (ترتیب شیرها ۲→۳→۱)، در سنگی نشانه‌ها (پ م ص ف)
- **۸ فصل داستانی** با اهداف فارسی مرحله‌به‌مرحله
- **۲ پایان متفاوت:** «خروج» و «ماندن» — بر اساس تصمیم پایانی بازیکن
- رخدادهای ترسناک اسکریپت‌شده (موج حوض، پنجرهٔ بازتابی، شبح پشت سر، درهای خودبسته، زمزمه، ضربه از داخل دیوار...)
- سیستم ذخیره JSON با دکمه «ادامه»
- موسیقی و صدا به‌صورت کامل **رویه‌ای** تولید شده (سانتور، نِی، درون‌مایه‌های ایرانی با سنتز)
- دو خط گفتار فارسی واقعی (TTS) با افکت رادیو و کاست قدیمی
- کنترل لمسی کامل اندروید (جوی‌استیک + نگاه لمسی + دکمه‌ها) و کیبورد/ماوس برای دسکتاپ
- منوی تنظیمات کاربردی: ۴ اسلایدر صدا، حساسیت نگاه/لمس، کیفیت تصویر، لرزش

## نصب روی اندروید
۱. فایل `HOZ_KHAMOOSH.apk` را روی گوشی منتقل کنید.
۲. از تنظیمات، «نصب از منابع ناشناس» را برای مرورگر/فایل‌منیجر فعال کنید.
۳. روی APK بزنید و نصب کنید (امضا: Samiee Game Studio — release-signed).
۴. بازی را در حالت **افقی** اجرا کنید.

> نام بسته: `com.SGS.HozKhamosh` — نسخه 1.0.0 — حداقل اندروید ۷.۰

## اجرای نسخه دسکتاپ (برای توسعه)
پروژه را با Godot 4.7 باز کنید:
- WASD: حرکت | ماوس: نگاه | E: تعامل | F: چراغ‌قوه | C: خم‌شدن | I: وسایل | Esc: مکث

## ساختار پروژه
```
project.godot            ← تنظیمات، اتولودها، رندر Mobile
scenes/main.tscn         ← صحنه ورودی
scripts/autoload/        ← fa(متن‌ها)، GameState، SaveSys، AudioMgr، Horror، UIH، EventBus
scripts/game/            ← house_builder، house_props، water_pool، game (منطق داستان)
scripts/player/          ← player.gd، touch_ui.gd
scripts/interact/        ← در، کشو، یادداشت، رادیو، شیر، فیوز، ساعت، آینه...
scripts/puzzles/         ← UI پازل‌ها
scripts/ui/              ← HUD، بررسی سند، موجودی، مکث
scripts/menu/            ← منوی اصلی با پس‌زمینه سینمایی حیاط
scripts/endings/         ← پایان A و B
assets/                  ← بافت‌ها، صداها، فونت وزیرمتن (OFL)
```

## ساخت مجدد APK
```bash
godot --headless --path . --export-release "Android" HOZ_KHAMOOSH.apk
```
(نیازمند Android SDK + قالب‌های خروجی 4.7.2)
